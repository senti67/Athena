# ATHENA 14 Specialized AI Analytical & Operational Agents

|---|---|---|
| **Technical Agent** | Analytical | Multi-timeframe indicators (EMA, RSI, MACD, Bollinger Bands, ATR, VWAP). |

| **Fundamental Agent** | Analytical | Discounted Cash Flow, ROE, ROIC, debt-to-equity, and valuation multiples. |
| **Sentiment Agent** | Analytical | FinBERT NLP sentiment scoring on news, Reddit, and analyst releases. |

| **Pattern Discovery** | Analytical | Ascending triangles, consolidation motifs, and harmonic breakout geometry. |

| **Data Quality Agent** | Operational | Ingestion integrity validator computing DATA_QUALITY_SCORE (0.0 to 1.0). |
| **Compliance Agent** | Operational | Verifies wash-sale rules, restricted lists, and leverage constraints. |
| **Cost Analysis Agent** | Operational | Estimates bid-ask spread, slippage, and broker commission drag. |
| **Research Agent** | Synthesis | Qualitative synthesis across SEC filings, transcripts, and thesis drivers. |
